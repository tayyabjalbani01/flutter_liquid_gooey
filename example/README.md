# Flutter Liquid Gooey Example

A runnable, single-file interactive showcase application demonstrating the core capabilities of [`flutter_liquid_gooey`](../README.md).

---

## What This Example Demonstrates

- **[`LiquidParent`](../README.md#1-liquidparent):** Expandable Plus trigger button with instant touch expansion wobble and delayed merge absorption recoil.
- **[`LiquidChild`](../README.md#2-liquidchild):** Satellite droplet buttons with transit flight motion blur and settling landing bounce.
- **[`LiquidGooeyGroup`](../README.md#3-liquidgooeygroup):** GPU Impeller fragment shader blending with automatic cross-platform vector bridge fallback.
- **[`LiquidItem`](../README.md#4-liquiditem):** Standalone iOS press wobble button with instant scale-up and jelly release.

---

## Running the Example

Run this project on your connected device or emulator:

### Mobile (Android / iOS)
```bash
flutter run
```

### Web
```bash
flutter run -d chrome
```

### Desktop (macOS / Windows / Linux)
```bash
flutter run -d macos
# or
flutter run -d windows
# or
flutter run -d linux
```
